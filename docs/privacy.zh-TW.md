# 隱私權政策：MultiList for TradingView

生效日期：2026-11-10

MultiList for TradingView（以下稱「本插件」）是非官方工具，與 TradingView 無關，也未獲其授權或背書。

本插件有兩個會把資料送到我們伺服器的選擇性功能：Google 登入（第 3 節）和匿名分享（第 4 節）。兩者互相獨立。兩個都不用時，不會有任何資料送到我們的伺服器。

## 1. 存在你瀏覽器的資料

- 你的分組、分頁、代碼存放在 Chrome 的同步儲存，會隨你的瀏覽器帳號同步。
- 你開始使用本插件的日期存放在 Chrome 的同步儲存。只有在你登入時，才會送到我們的伺服器。
- 你對分享的選擇、匿名分析 ID、雜湊用的鹽（見第 4 節）存放在 Chrome 的同步儲存。
- 你選的背景與文字顏色存放在 Chrome 的同步儲存。
- 你的 API key 只存在你的裝置上，永遠不會送到我們的伺服器。
- 如果你同意分享，還沒上傳的清單變化會存在你的裝置上。
- 如果你登入，登入狀態、你的信箱，以及上次同步時的清單副本會存在你的裝置上。登出會刪除登入狀態和信箱。

## 2. 向第三方服務發出的請求

以下請求都從你的瀏覽器直接送出，不經過我們的伺服器。

報價來源包括：

- TWSE MIS（mis.twse.com.tw）
- Yahoo Finance
- Binance
- Fugle
- Alpaca

這些服務會收到被查詢的代碼。Fugle 和 Alpaca 還會收到你輸入的 API key，因為它們的服務需要。

你開著的 TradingView 分頁會向 TradingView 網站送出請求：搜尋代碼時送出你輸入的搜尋文字，切換圖表時送出代碼。匯入 TradingView 觀察清單時，本插件會用你的 TradingView 登入讀取清單。匯入的清單只存在你的瀏覽器。

這些服務依它們自己的隱私權政策處理這些資料。

## 3. 選擇性的 Google 登入

登入是選擇性的。不登入時，本插件照常運作，清單只透過 Chrome 同步。登入後，清單也會經過我們的伺服器，同步到你的其他瀏覽器，例如 Chrome 和 Edge。登入前，登入視窗會告訴你，登入後清單會同步到你的其他設備和瀏覽器，並附上本政策的連結。

我們從 Google 只取得你的 Google 帳號編號和信箱。我們不會取得你的姓名、大頭照、密碼，或任何其他 Google 資料。

我們的伺服器儲存：

- 你的 Google 帳號編號和信箱
- 你的清單：分組、分頁、代碼，包括分組名稱、分頁名稱、代碼的顯示名稱（例如「台積電」），以及分組是否收合等顯示設定
- 你開始使用本插件的日期、帳號建立的日期、最近一次登入的時間、最近一次同步的時間
- 你的登入 session，每次登入一個。我們只儲存每個 session 的單向雜湊值，以及它建立和最近使用的時間。

你登出時，session 就會失效。如果登出當下連不到我們的伺服器，伺服器上的 session 會在大約一年沒有使用後失效。

我們用這些資料來：

- 在你的瀏覽器之間同步清單。
- 維持登入狀態，並顯示你目前登入的帳號。
- 知道你使用本插件多久。之後我們可能用這些日期給早期用戶優惠。

我們不會寄行銷信件給你。

我們對從 Google API 取得之資訊的使用，符合 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy)，包括 Limited Use（有限使用）規定。

## 4. 選擇性的匿名分享

在你於本插件的同意視窗按下「同意」，或在本插件右上角「⋯」選單的「匿名分享」打開「匿名分享觀察清單」之前，分享都是關閉的。你可以隨時在那裡關閉。它和登入無關：兩個功能可以只用一個、兩個都用，或都不用。

若你同意，本插件會送出：

- 一個隨機產生的匿名分析 ID
- 每一次加入或移除代碼的事件（時間、代碼、分組 ID）
- 每次上傳時附上目前各分組的代碼清單（只有代碼、分組 ID、分頁 ID）
- 插件版本
- 技術欄位：隨機的上傳 ID，以及這次上傳涵蓋的時間範圍

說明：

- 上傳前，分組 ID 和分頁 ID 會換成加鹽的單向雜湊值。鹽存放在 Chrome 的同步儲存，永遠不會送到我們的伺服器。
- 分享的資料絕不包含分組名稱、分頁名稱、代碼的顯示名稱、你的信箱或帳號。上傳的請求絕不帶登入資訊。
- 上傳頻率：同意時上傳一次，之後在瀏覽器開著時大約每 7 天一次。
- 我們不會把分享的資料和帳號資料比對或合併。

## 5. 我們不收集的資料

- API key
- 瀏覽紀錄
- 你的姓名或大頭照
- 密碼
- 不登入時：你的信箱、分組名稱、分頁名稱

我們不儲存 IP 位址。

## 6. 資料用途

- 提供與改善插件功能，包括之後可能在插件內提供的彙總市場趨勢功能（例如熱門代碼統計）。這些統計只使用匿名分享的資料。
- 不出售資料。
- 不用於廣告。
- 不轉給第三方，例外只有代管服務供應商（Cloudflare）與法律要求。
- 人只會檢視彙總且匿名化的統計。除非經過你的同意（例如處理你回報的問題）、為了安全，或法律要求，否則沒有人會讀你的帳號資料或同步的清單。

我們對從本插件取得之資料的使用，符合 Chrome Web Store User Data Policy，包括 Limited Use（有限使用）規定。

## 7. 保存與刪除

**帳號資料**

- 你的帳號資料和同步的清單，會保存到你刪除帳號為止。
- 登出不會刪除它們。
- 要刪除時，打開本插件右上角的「⋯」選單，選「刪除帳號…」並確認。這會一次刪除你同步的清單、登入 session 和帳號資料，無法復原。
- 刪除的資料可能在代管服務供應商的備份中保留最多 30 天。
- 你裝置上的清單會保留。你的其他瀏覽器會被登出。
- 你也可以寄信要求我們刪除帳號（第 11 節）。

**匿名分享的資料**

- 已分享的資料無限期保存。
- 關閉分享會停止之後的上傳，並刪除插件內尚未送出的紀錄。
- 已經送出的資料會保留在我們這邊。它是匿名的，也沒有和你的帳號連結，所以我們無法依刪除要求找到它。

## 8. 存放位置

帳號資料、同步的清單、分享的資料都存放在 Cloudflare（Workers 與 D1 資料庫）。資料以 HTTPS 傳送。我們的伺服器不記錄請求的內容。

## 9. 兒童

本插件不針對 13 歲以下兒童。

## 10. 政策變更

政策變更時，我們會更新「生效日期」。如果收集的資料種類有改變，我們會在收集前再次詢問你的同意。
