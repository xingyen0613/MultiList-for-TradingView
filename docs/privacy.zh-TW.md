# 隱私權政策：MultiList for TradingView

生效日期：[EFFECTIVE_DATE]

MultiList for TradingView（以下稱「本插件」）是非官方工具，與 TradingView 無關，也未獲其授權或背書。

## 1. 存在你瀏覽器的資料

- 你的分組、分頁、代碼存放在 Chrome 的同步儲存，會隨你的瀏覽器帳號同步。
- 你的 API key 只存在你的裝置上，永遠不會送到我們的伺服器。

## 2. 向第三方資料來源請求報價

本插件從你的瀏覽器直接請求報價，不經過我們的伺服器。資料來源包括：

- TWSE MIS（mis.twse.com.tw）
- Yahoo Finance
- Binance
- Fugle
- Alpaca
- TradingView 網站

這些服務會收到被查詢的代碼，並依它們自己的隱私權政策處理。

## 3. 選擇性資料分享

在你於插件的同意視窗按下「同意」之前，分享都是關閉的。你可以隨時在插件的「設定」中關閉。

若你同意，插件可能送出兩類資料：

**a. 安裝登記**

- 一個隨機產生的匿名安裝 ID
- 首次安裝日期
- 插件版本

**b. 清單變化**

- 一個隨機產生的匿名分析 ID
- 每一次加入或移除代碼的事件（時間、代碼、隨機分組 ID）
- 每次上傳時附上目前各分組的代碼清單（只有代碼與隨機分組 ID）
- 插件版本

說明：

- 上傳頻率：瀏覽器開著時，大約每 7 天一次。
- 兩個 ID 分開送出、分開存放，互相不連結。

## 4. 我們不收集的資料

- 分組名稱
- 分頁名稱
- API key
- 瀏覽紀錄
- Email
- 姓名

我們不儲存 IP 位址。

## 5. 資料用途

- 提供與改善插件功能，包括之後可能在插件內提供的彙總市場趨勢功能。
- 不出售資料。
- 不用於廣告。
- 不轉給第三方，例外只有代管服務供應商（Google Cloud）與法律要求。
- 人只會檢視彙總且匿名化的統計。

我們對從本插件取得之資料的使用，符合 Chrome Web Store User Data Policy，包括 Limited Use（有限使用）規定。

## 6. 保存與關閉分享

- 已分享的資料無限期保存。
- 關閉分享會停止之後的上傳，並刪除插件內尚未送出的紀錄。
- 已經送出的資料會保留在我們這邊。它是匿名的，無法對應回你個人。

## 7. 存放位置

分享的資料存放在 Google Cloud（Firestore，台灣 asia-east1 區域）。

## 8. 兒童

本插件不針對 13 歲以下兒童。

## 9. 政策變更

政策變更時，我們會更新「生效日期」。如果收集的資料種類有改變，插件會再次詢問你的同意。
